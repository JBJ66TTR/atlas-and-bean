# Atlas & Bean ☕

A modern coffee shop website inspired by Moroccan hospitality and the beauty of the Atlas Mountains.

## About the Project

Atlas & Bean is a responsive coffee shop website created as a web development and product engineering project. The website presents the café's brand, featured drinks, story, and contact information in a simple and welcoming design.

## Features

* Responsive design for desktop and mobile devices
* Navigation menu
* Coffee shop landing page
* Featured coffee menu
* About section
* Contact section
* Smooth scrolling interaction
* Clean and modern visual design

## Technologies Used

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## Project Structure

```text
atlas-and-bean/

```

## Getting Started

To view the project locally:

1. Clone the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

## Live Website

The website can be hosted using GitHub Pages.
